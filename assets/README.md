# Folder Aset Museum Kenangan

- **Foto kenangan**: taruh di `assets/photos/` (mis. `assets/photos/2024-1.jpg`), lalu isi field `image` di `js/data.js`.
  - Tips biar website tetap ringan di HP: kompres foto ke ukuran lebar ±1280px (format `.jpg` atau `.webp`).
- **Musik latar (opsional)**: taruh file MP3 di `assets/music.mp3` (atau ubah `BIRTHDAY.music` di `js/data.js`). Tekan **M** atau tombol **♪** di kanan atas untuk on/off.
